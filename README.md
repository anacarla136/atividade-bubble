# Bubble Sort

Trabalho acadêmico sobre o algoritmo de ordenação Bubble Sort.

## Passo a passo

1. Criar uma lista de elementos.
2. Comparar os elementos vizinhos.
3. Trocar os elementos quando estiverem na ordem incorreta.
4. Repetir as comparações até que todos os elementos estejam ordenados.
5. Exibir a lista ordenada.

## Objetivo

Demonstrar o funcionamento do algoritmo Bubble Sort e sua aplicação na ordenação de elementos.
